# MantStock - Práctica Integradora 1 (DevOps)

## Propósito
Aplicación web contenerizada para el control de visitas, integrando Node.js, Redis, Docker, Docker Compose, Docker Hub y GitHub Actions, sin afectar el sistema original en PHP.

## Requisitos
- Node.js v20 o superior
- Docker y Docker Compose
- Git

## Comandos de ejecución local (Desarrollo)
1. Instalar dependencias: `npm install`
2. Ejecutar pruebas: `npm test`
3. Iniciar la app (requiere Redis local): `npm start`
